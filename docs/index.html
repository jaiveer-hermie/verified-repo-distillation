Verified Repo Distillation

Every "fine-tune on your codebase" tool mines git log into (context → patch) pairs and assumes each commit was correct. We execute the commit's own tests on both sides of every commit, keep only the pairs that provably flip a test from red to green — then measure what that proof is actually worth.

Solved sets: 2 shared, 2 base-only, 1 tuned-only → tuning is net −1 task. Application rate collapses 17→6 (Fisher p = 0.0047) while pass-per-applied doubles. The adapter did not learn the repo; it lost the output contract. A patch that fails to parse scores zero, so that trade is negative.
