Verified Repo Distillation

Every other “fine-tune on your codebase” tool mines git history and assumes each commit was correct. This one runs the tests — and shows you the ones that were never correct.

The funnel

Commits in, commits out, and why the rest died. Numbers below are produced by run.py ingest and run.py gate on a real repository — no hand-counting.

Rejected: the test passed before the fix

These commits add a test that does not test the commit. Injected against the unpatched parent, it is already green. Any pipeline that mines history without executing anything ingests these as ground truth.

Verified pairs

The injected test failed on the parent and passed after the patch. These are the only commits that reach training.

Scoring in the evaluation is execution, never a judge: the produced diff must apply to the parent tree and the commit’s own test must pass afterwards.
